SAP BD will have 3 puzzles.

Puzzle 1:
KeypadMemoryPuzzle puzzle has a random generated sequence the player has to remember, 
and then they have to input the correct sequence in order to move onto the next round. 
There will be 3 rounds where each round gets progressively longer and thus harder.

Puzzle 2:
Players will have to place 5 correct fuses in the correct location. There are no markings on the fuses to differentiate them.
To solve this puzzle, you need to make educated guesses about the location of the fuses.
Initially, information is limited, so you will need to place them randomly.
After pressing a button, number of green lights from 1 to 5 will turn on, allowing you to know how many fuses are placed correctly.
The catch is you do not know which fuses are placed correctly, so the players have to move the fuses around to see the change in lights.
To complete this puzzle, place all 5 fuses in the correct location and press the confirm button.

Puzzle 3:
This puzzle will have 3 spinning circular disks, each with a single circular hole in a different location.
Players can slow down the rotational speed of each disk, but never completely (stationary), by using 3 separate potentiometers.
Underneath each rotating disk, there is a laser.
The objective is to get each one of the lasers (3 in total) to shine through the respected holes of each disk at the same time.

Timer:
There will be a timer displayed for players to see how long they have to defuse the remaining puzzles. The exact time to defuse the bomb has still been undecided.
The difficulty can be gauged after all puzzles have been implemented.
Possible measures to prevent teams from pressing random buttons for Puzzle 1, is to add a time penalty to each incorrectly typed answer.

Theme:
The puzzles will be placed in a suitcase, and be made to look like an explosive device (pretend of course). This is a popular trope seen in spy movies and TV series.
The players will take the role of spies looking to defuse the bomb before it goes off.

Extra:
An information leaflet will be provided in how each puzzle works, yet this might also be removed to allow players to form their own interpretation of the puzzles.
